# 오늘의 서당 · Android QA

## 검증 환경

- Android 15(API 35) 격리 에뮬레이터와 Android 16(API 36) 알림 검증용 격리 에뮬레이터, 디버그 APK.
- 이전 APK에서 자유 연습 5문제를 풀어 1정답, 1 XP, 수집 성어 ‘감개무량’을 생성했다. 비행기 모드에서 앱 데이터를 유지하며 새 APK를 설치했다.
- 화면·저장 상태는 ADB와 UIAutomator 화면 트리로 확인했다. 날짜 변화는 테스트 에뮬레이터의 시간대를 변경해 로컬 날짜를 2026-11-05에서 2026-11-06으로 넘겨 재현했다.

## 확인 결과

| 기준 | 관찰 결과 |
|---|---|
| AC-S1 · 오프라인·기존 데이터 | 오프라인 초기 상태와 이전 APK에서 오프라인 업데이트한 상태 모두 권한 팝업 없이 오늘의 3문제를 열었다. 업데이트 후 기존 5문제·정답률 20%·1 XP·감개무량 수집을 확인했다. 자유 연습은 여전히 5문제다. |
| AC-S2 · 이어풀기 | 힌트를 펼친 뒤 강제 종료하고 돌아오니 동일한 문장, 보기 순서, 힌트가 유지됐다. 정답을 선택하고 다시 강제 종료하니 같은 문항과 풀이가 유지됐다. |
| AC-S3 · 수집·중복 방지 | 세 번째 답을 저장한 뒤 강제 종료해도 정답과 도장이 남았다. 최종 APK에서는 홈의 ‘오늘 공부를 마쳤어요’ → ‘오늘의 기록 보기’가 결과를 바로 연다. 같은 날 결과 재확인으로 도장이 늘지 않았다. 서고에는 이전 ‘감개무량’과 실제로 새로 맞힌 ‘고진감래’가 남았고, 복습에서 다시 맞힌 ‘고진감래’는 신규 획득으로 표시되지 않았다. 전부 틀렸을 때도 도장 한 개를 얻었다. |
| AC-S4 · 날짜·복습 | 세 번째 문항을 푸는 중 로컬 날짜를 바꿔도 진행 중 화면과 도장은 시작한 날짜에 남았다. 다음 로컬 날짜에 무료 힌트를 쓴 정답과 오답이 다른 생활 문장으로 복습에 나왔다. 복습 후보가 세 개였지만 다음 세트의 첫 두 문제만 복습, 세 번째는 새 문제였다. 내장 7세트는 21개 성어, 각 3개의 유효한 보기와 별도 복습 문장을 확인했다. |
| AC-S5 · 알림 | 초기 실행에는 권한 요청과 알림 작업이 없었다. 결과 화면에서 켜기를 눌러야 OS 권한 창이 열렸으며 거절 후 기기 알림 설정에 들어갈 수 있었다. 설정에서 켜고 OS 권한을 허용하면 작업이 예약됐고, 실제 알림을 눌러 앱이 열린 상태에서도 오늘 학습으로 이동했다. OS 권한 회수와 재허용, 앱 설정 끄기에 따라 작업이 취소되거나 다시 예약됐다. 학습 완료 직후 결과 화면에서 알림을 허용한 날에는 WorkManager가 실행됐지만 알림을 표시하지 않았다. |
| AC-A11Y · 큰 글씨 | 320dp 폭과 글꼴 크기 2배에서 홈 진입, 문항·선택지, 정오답, 다음 동작, 완료 내용을 스크롤로 확인했다. 큰 글씨에서 잘리던 하단 탭은 짧은 한국어 라벨로 바꿨다. 최종 APK의 라벨 표시, 접근성 트리 및 서당·서고 이동을 다시 확인했다. |

단위 테스트 82개와 Android 디버그 및 릴리스 APK 빌드가 통과했다. 로컬 날짜 기준 복습 간격, 동시 제출의 중복 방지와 Realm v2 → v3 데이터 마이그레이션을 자동 테스트에 포함했다.

## 범위

이 검증은 디버그 빌드에서 앱 흐름과 저장 상태를 확인했다. TalkBack의 실제 읽기 순서, 회전 시 접근성 동작, 제조사별 배터리 제약과 운영 빌드의 알림 도착 시각은 별도 검증 대상이다. 실제 사용자 사용성 가설과 배포 후 재방문율은 출시 후 판단한다.

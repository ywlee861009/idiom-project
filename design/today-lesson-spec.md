# 오늘의 서당 · PD 상세 설계 및 개발 인계

범위는 [PO 에픽 E-01의 S1–S5](../tickets/today-lesson-epic.md)다. 40대 이상 사용자가 설치 직후부터 짧게 공부하고, 다음 방문에 헷갈린 성어를 다른 문장에서 다시 풀 수 있게 한다. [기존 디자인 가이드](../GUIDE_FOR_DESIGNER.md)의 한지 배경, 먹색 타이포그래피, 차분한 정오답 표현과 서당·서고·내 정보의 탐색 구조를 사용한다.

설계에는 [프로젝트에 설치한 Product Design and UX 스킬](../.agents/skills/product-design-and-ux/SKILL.md)의 상태 전이, 인터페이스 계약, 개발 인계 지침을 적용했다. 스킬의 [원본 커밋](https://github.com/magnus919/agent-skills/tree/4f03205616b01360374f458f471791188f448591/product-design-and-ux)과 [MIT 라이선스](../.agents/skills/product-design-and-ux/LICENSE.md)를 함께 보관한다.

## 설계 근거와 정보 구조

| 스토리 | 프로젝트에서 관찰한 근거 | 화면 결정 |
|---|---|---|
| S1 · 첫 진입 | [앱 진입점](../cmp/composeApp/src/commonMain/kotlin/App.kt)은 자료 동기화가 끝나야 홈을 표시한다. | 서당에서 일일 학습을 첫 행동으로 노출한다. 내장 자료를 쓰고 원격 갱신은 백그라운드에서 처리한다. |
| S2 · 이어풀기 | [기존 UX](../UI_FLOW.md)는 5문제에 여러 입력 방식을 섞는다. | 오늘의 서당은 키보드 없는 3지선다 3문제로 고정한다. 자유 연습은 기존 6종·5문제 흐름으로 연결한다. |
| S3 · 수집과 기록 | [기존 결과](../cmp/composeApp/src/commonMain/kotlin/com/kero/idiom/ui/RewardScreen.kt)는 방금 답한 성어와 별개로 보상 카드를 뽑는다. | 완료 도장과 수집을 별도 성취로 표시한다. 이번 세트로 서고에 실제 추가된 성어만 신규로 표시한다. |
| S4 · 복습 | [기존 성어 모델](../cmp/data/src/commonMain/kotlin/com/kero/idiom/data/local/model/IdiomEntity.kt)은 노출·정답 횟수만 저장한다. | 일일 학습 응답으로 복습일을 계산하고, 복습에서는 같은 성어의 다른 문장을 제시한다. |
| S5 · 알림 | [기존 알림](../cmp/composeApp/src/androidMain/kotlin/com/kero/idiom/notification/ReminderWorker.kt)은 일반 앱 실행으로 연결된다. | 알림을 사용자가 선택한 뒤 예약하고, 누르면 현재 날짜의 일일 학습 상태를 연다. |

서당에서 오늘의 서당과 자유 연습에 각각 진입한다. 오늘의 서당은 문항·풀이 → 오늘의 기록 → 서당 또는 서고 순서다. 퀴즈 안에서는 하단 탭을 접고 뒤로 가기 또는 화면의 ‘서당으로’로 빠져나올 수 있다. 알림 진입에도 같은 경로를 써서 중복 화면이나 세트를 만들지 않는다. 내 정보 → 설정의 학습 알림은 사용자가 예약 여부를 변경하는 경로다.

## 화면과 상태 전이

| 상태 | 표시 내용 | 조작과 결과 |
|---|---|---|
| 홈 · 시작 전 | ‘오늘의 서당’, 오늘 날짜, ‘객관식 3문제 · 약 1분’, ‘이번 주 0일 공부 · 목표 3일’ 같은 현황 | 주 버튼 ‘오늘의 3문제 풀기’, 부 버튼 ‘자유 연습’. 정답은 제목이나 예고 문구에서 드러나지 않게 한다. |
| 홈 · 진행 중 | ‘3문제 중 1문제 답했어요’처럼 저장된 응답 수 | ‘이어서 풀기’로 같은 날의 세트와 화면 상태를 복원한다. 날짜가 바뀐 뒤 홈에 다시 오면 새 날짜 상태를 보여준다. |
| 홈 · 오늘 완료 | ‘오늘 공부를 마쳤어요’, 실제 이번 주 완료일 수 | ‘오늘의 기록 보기’. 같은 결과를 다시 열어도 수집이나 도장을 다시 지급하지 않는다. 더 풀려면 ‘자유 연습’을 사용한다. |
| 문항 · 답변 전 | ‘1 / 3 · 새 문제’ 또는 ‘1 / 3 · 복습’, 생활 장면, 선택지 3개 | 한 번 누르면 답을 제출한다. ‘무료 힌트 보기’는 정답 글자를 직접 보여주지 않는 단서를 펼친다. 힌트 노출 자체를 저장한다. 일일 세트는 시간 제한, 광고, 키보드 없이 진행한다. |
| 문항 · 풀이 | 답이 저장되면 ‘맞았어요’ 또는 ‘다음에 다시 만나요’, 올바른 성어의 한글·한자·뜻 | 추가 답변을 잠근다. 1·2번은 ‘다음 문제’, 3번은 ‘오늘의 기록 보기’를 눌러 이동한다. 세 번째 답을 저장한 뒤에도 해당 풀이를 그대로 보여준다. |
| 완료 | ‘서첩에 도장을 찍었어요’, 완료일, ‘이번 주 2일 공부 · 목표 3일’, 실제 신규 수집 목록 | 신규 수집이 있을 때 ‘서고에서 보기’, 언제나 ‘서당으로 돌아가기’. 신규 수집이 0개면 ‘오늘 푼 성어를 기록했어요’. 전부 틀려도 동일한 완료 도장을 준다. |
| 일시 오류 | ‘문제를 준비하지 못했어요’ 또는 ‘답을 저장하지 못했어요’ | ‘다시 시도’와 ‘서당으로’. 이미 저장한 선택·힌트·진행은 유지한다. 완료·수집 문구는 로컬 저장 성공을 확인한 뒤 보여준다. |
| 알림 안내 | 첫 일일 결과의 ‘공부할 시간을 알려드릴까요?’ | 사용자가 ‘학습 알림 켜기’를 누르면 권한 흐름으로 이동한다. 거절하거나 미뤄도 결과는 그대로이며 설정에서 다시 선택할 수 있다. |

## 날짜, 저장, 수집 계약

- 세트의 키는 기기 로컬 날짜다. 첫 진입 때 성어 ID, 생활 장면, 정답·뜻·힌트, 보기 순서, 복습 여부를 그날 계획에 고정한다. 화면 회전, 프로세스 종료 및 원격 콘텐츠 갱신으로 같은 날짜의 출제가 바뀌지 않는다.
- 현재 세트를 푸는 중 자정을 넘으면 기존 세트를 계속 풀 수 있다. 완료 도장은 세트 날짜로만 남긴다. 그 화면을 나가거나 다음 날 다시 실행하면 현재 날짜의 세트를 연다. 주간 집계는 로컬 월요일부터 일요일까지 완료한 서로 다른 날짜를 센다. 3일 이상이면 ‘목표 달성’과 실제 일수를 함께 표시한다.
- 답안·힌트·다음 문제로 넘어간 위치를 저장한다. 세 번째 답의 저장에서 완료 도장, 수집, 복습 갱신을 확정한다. 날짜와 문항 키로 중복을 막아 연타, 재시도, 종료 후 재진입으로 결과가 두 번 기록되지 않게 한다. 마지막 풀이에서 앱이 종료되어도 완료 기록을 다시 열 수 있다.
- 신규 획득은 정답이면서 그 시점에 서고에 없던 성어다. 자유 연습에서 이미 수집한 성어도 맞힌 개수에 포함하되 신규 획득은 추가하지 않는다. 저장한 신규 수집 목록은 같은 결과를 다시 볼 때에도 유지한다.
- 일일 학습의 출석·정오답은 ‘오늘의 서당’ 기록으로 관리한다. 자유 연습의 XP·레벨·통계는 기존 기준대로 계산하고 서고는 공유한다. 앱 업데이트는 기존 Realm과 DataStore 값을 보존해야 한다.

## 출제와 복습 계약

- 첫 7일은 내장 편집 세트로 시작한다. ‘힘든 연습 끝에 첫 무대에 섰어요’의 보기는 ‘우공이산 / 고진감래 / 전화위복’이다. ‘어려운 시간이 지나 좋은 결과가 찾아왔어요’라는 힌트를 주고, 복습에서는 ‘몇 달 준비한 자격시험에 드디어 합격했어요’처럼 문장을 바꾼다.
- 내장 콘텐츠는 안정적인 성어 ID와 생활 장면, 다른 맥락의 복습 문장, 중복 없는 보기와 정답, 뜻풀이를 제공한다. 첫 7일 이후에도 내장 자료로 세트를 생성한다. 원격 자료에서 빠진 성어의 저장된 세트와 기존 수집 기록은 보존한다.
- 오답·힌트 사용 성어는 다음 날부터 복습할 수 있다. 처음 무힌트 정답은 3일 뒤, 복습에서의 무힌트 정답은 7일 뒤를 다음 후보일로 둔다. 날짜 간격은 로컬 달력 일수로 계산한다. 자정을 넘어 완료한 경우에는 실제 완료일을 복습 기준일로 쓴다.
- 도래한 후보는 기한이 이른 순서로 선택하고 같은 기한은 안정적인 성어 ID로 정렬한다. 하루 3문제 중 최대 두 문항을 복습에 배정하고 나머지는 새 출제로 채운다. 한 세트에 같은 성어를 두 번 넣지 않는다. 넘치는 후보는 다음 날에도 남는다.
- 새 문제는 가능하면 아직 일일 출제로 보지 않은 성어를 고른다. 후보가 적으면 내장 자료에서 현재 세트에 없는 문항으로 채운다. 자료가 유효하지 않아 3문제를 만들 수 없는 경우에만 실패 상태로 보내고 진행 상태는 보존한다.

## 알림 계약

- 신규 설치와 직접 설정한 값이 없는 기존 설치는 기본 꺼짐이다. 기존 사용자가 저장한 켜짐·꺼짐은 유지한다. 시스템 권한만 있는 상태는 앱의 명시적 선택으로 해석하지 않는다.
- Android 13 이상에서는 결과 또는 설정에서 사용자가 켜기를 선택할 때만 권한을 요청한다. 앱 설정과 OS 상태가 모두 켜졌을 때 예약한다. 거절하면 꺼짐을 유지한다. 이미 OS에서 차단된 경우 시스템 설정에서 허용할 수 있는 경로를 제공한다.
- 기기 시각으로 하루 최대 한 번, 기본 오전 8시 무렵에 로컬 알림을 예약한다. 발송 작업에서 현재 날짜를 다시 계산해 당일 완료, 앱에서 끔, OS 차단 중 하나라도 해당하면 표시하지 않는다. 끄면 예약과 표시 중인 학습 알림을 취소한다.
- 제목 ‘오늘의 서당’, 본문 ‘사자성어 3문제로 짧게 공부해 보세요.’ 정답·오답과 성어 목록은 알림에 넣지 않는다. 알림을 누른 날의 상태를 열어 미완료면 시작·이어풀기, 완료면 그날의 기록으로 이동한다.

## 접근성과 데이터 경계

- 질문과 답안에는 본문보다 큰 테마 역할을 적용한다. 탭 가능 영역은 가로·세로 최소 48dp로 둔다. 320dp 폭, 글자 크기 2.0배에서는 장면·보기·버튼이 줄바꿈과 세로 스크롤로 모두 노출되어야 한다. 회전해도 응답이나 힌트가 초기화되지 않는다.
- 읽기 순서는 날짜/진행 → 질문 → 보기 → 힌트/풀이 → 다음 동작이다. 정오답을 텍스트와 색으로 알린다. 풀이가 열릴 때 읽을 수 있게 알리고 다음 문제로 넘어가면 새 문항의 문맥이 먼저 읽히게 한다. 한자는 한글 성어와 함께 보여준다. 애니메이션이 없어도 진행할 수 있다.
- 학습 날짜, 응답, 힌트, 수집, 복습 후보와 알림 선택은 기기 안에서 처리한다. 신규 원격 이벤트는 이번 범위 밖이다. 이후 계측을 검토할 때도 성어·답안 문자열과 알림 수신 동의 내역은 전송 대상에서 제외한다.

| AC-S5 | 거절·허용·나중·끄기·OS 권한 취소와 알림 탭을 확인한다. | 자발적 선택 전, 당일 완료 또는 OS 차단 시 발송하지 않는다. 알림을 누르면 그 시점의 일일 학습을 연다. |
| AC-A11Y | 작은 폭, 글자 크기 2배, TalkBack 또는 접근성 트리로 처음부터 완료까지 확인한다. | 줄 잘림 없이 모두 조작 가능하며 진행과 정오답을 말과 글로 확인할 수 있다. |

개발은 위 표의 정상·실패·복구 흐름을 구현하고, QA는 기기/API, 재현 조건, 관찰 결과를 기록한다. 시간 경계와 저장 실패는 제어 가능한 테스트 날짜와 로컬 데이터로 검증한다. 5명 중 4명 이상 무도움 완료와 완료 시간 중앙값 1분은 PO가 실제 사용성 검증에서 판단할 가설이다.

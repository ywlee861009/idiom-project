# PO 에픽 · 오늘의 서당

## E-01 · 매일 한 번 들르는 사자성어 공부

40대 이상 이용자가 짧은 생활 속 퀴즈를 부담 없이 시작하고, 헷갈린 성어를 다음 방문에 다시 익힐 수 있게 한다. 주 사용자 흐름은 앱 열기 → 오늘의 3문제 → 실제로 담은 성어와 공부 도장 확인 → 다음 방문 복습이다.

첫 전달 범위는 아래 S1–S5다. 주제별 서고는 재방문과 사용성 결과를 본 뒤 별도 에픽으로 검토한다. 기존 자유 연습, 정답으로 수집한 성어, 학습 기록, XP·레벨, 개인정보 기능은 기존 데이터와 호환되어야 한다.

| 스토리 | 사용자 가치 | 인수 기준 |
|---|---|---|
| S1 · 열자마자 오늘 공부 시작 | 네트워크와 무관하게 내가 할 일을 바로 알 수 있다 | 내장 자료로 오프라인 첫 실행과 출제가 된다. 홈에서 오늘의 학습과 기존 자유 연습을 구분한다. |
| S2 · 같은 날 이어서 풀기 | 키보드나 유료 힌트 부담 없이 짧게 공부할 수 있다 | 3문제, 무료 힌트, 피드백, 이어풀기가 동작한다. 이미 응답한 문제와 힌트 상태가 다시 열어도 유지된다. |
| S3 · 실제 학습의 결과 확인 | 틀려도 공부한 날이 남고, 내가 맞힌 성어를 바로 확인한다 | 날짜별 도장을 한 번만 기록하고 월요일 시작 주간의 서로 다른 완료일을 센다. 서고에 새로 저장한 성어만 신규 수집으로 표시한다. |
| S4 · 다시 떠올리기 | 지난번 어려웠던 성어를 다른 상황에서 익힌다 | 오답·힌트 사용 성어는 다음 날부터, 무힌트 정답은 처음 3일 뒤부터 복습할 수 있다. 3문제 중 최대 2문제를 복습으로 배정하고 최소 1문제는 새 출제로 유지한다. |
| S5 · 원할 때만 알림 | 알림을 스스로 선택하고 오늘 학습으로 곧바로 이동할 수 있다 | 첫 완료 후 또는 설정의 명시적 선택에서 권한을 요청한다. 오늘 학습을 마치면 당일 알림을 보내지 않는다. 알림을 눌러 오늘 학습으로 이동하고 설정에서 끌 수 있다. |

## 검증할 가설

- 안내 없이 첫 세트를 끝내는 사용자가 5명 중 4명 이상이고 완료 시간 중앙값이 1분 안팎인지 검증한다.
- 첫 세트 시작 대비 완료 비율과 첫 완료 다음 날에 돌아와 한 문제 이상 푼 비율을 기준선과 비교한다. Play Console의 7일 재방문을 보조 지표로 본다.
- QA에서 동작과 데이터 보존을 확인한다. 재방문 개선 여부는 배포 후 이용 데이터로 판단한다.

## 역할 간 인계

- PO는 사용자 가치, 범위와 위 인수 기준을 관리한다.
- PD는 각 스토리의 정상·빈·실패·복구 상태, 화면 문구, 접근성, 날짜 경계와 상태 전이를 [상세 설계](../design/today-lesson-spec.md)에 정의한다.
- 개발자는 상세 설계에 따라 구현하고 QA는 스토리별 실제 결과와 남은 검증 범위를 보고한다.
